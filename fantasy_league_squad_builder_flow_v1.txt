Fantasy League V1 - Squad Builder Flow

1. OPEN SQUAD BUILDER
- User enters Squad Builder
- User sees £110M budget
- User sees remaining budget
- User sees squad slots remaining
- User sees current squad composition

2. PLAYER DISCOVERY
- User browses available players
- User can search by player name
- User can filter by:
  - Position
  - Club
  - Price

Player Card Displays:
- Player Name
- Club
- Position
- Current Price
- Total Fantasy Points
- Recent Form

Recent Form Rules:
- Use last 5 matches when available
- If fewer than 5 matches played, use all available matches
- Minimum 3 matches required to display form
- Fewer than 3 matches displays "Insufficient Data"

3. ADD PLAYER
- User selects a player
- System validates:
  - Remaining budget
  - Squad size limit
  - Position requirements
  - Club limit
- Player is added to squad
- Budget updates immediately

4. REMOVE PLAYER
- User removes a player
- Budget is refunded
- Squad updates immediately

5. SQUAD VALIDATION
System checks:
- 16 total players
- Exactly 2 goalkeepers
- Valid squad composition
- Budget does not exceed £110M
- Maximum 3 players from the same club

6. SET STARTING LINEUP
- User selects starting XI
- User selects a valid formation

Valid Formations:
- 3-4-3
- 3-5-2
- 4-3-3
- 4-4-2
- 4-5-1
- 5-3-2
- 5-4-1

Formation Rules:
- Exactly 1 Goalkeeper
- 3–5 Defenders
- 2–5 Midfielders
- 1–3 Forwards
- Total 11 players

7. CAPTAINCY
- User selects captain
- User selects vice-captain

8. SAVE SQUAD
- User saves squad
- System confirms successful save

9. GAMEWEEK EDITING
- User may edit unlocked players
- User may change lineup
- User may change captain/vice-captain
- Locked players cannot be modified

10. DEADLINE LOCK
- Players lock individually at exact kickoff
- Locked players remain unavailable for lineup changes

11. BENCH SCORING (V1)
- No automatic substitutions in V1 — deferred to V2
- Bench player points are added directly to the team's total score
- V2 will introduce automatic substitutions for non-playing starters

Club Limit
- Maximum 3 players from the same club
- Applies to the full 16-player squad
- System prevents adding a 4th player from the same club
