Milestone 5 — Bonus Points: Game State Goals.
    Build order: complete Milestone 3 in full before starting here.

    Concept: goals that dramatically change the match outcome carry extra fantasy weight.
    The exact base bonus/penalty values are TBD (see fantasy_league_v1_design.txt); the
    framework below is fixed.

    Scenarios:
        Winning goal   — scorer + assister of the decisive winning goal get heavy bonus
        Equalizing goal — scorer + assister of any goal that ties a deficit get heavy bonus
        Losing goal    — GKs and DEFs of the conceding team, plus own-goal scorers, get
                         heavy penalty for the goal that sealed their loss

    Timing multiplier (applied to the bonus/penalty, not the base event points):
        0–75 min:   1.0× (no boost)
        76–80 min:  1.2×
        81–85 min:  1.6×
        86–90 min:  2.0×
        90+ min:    2.5× (all added time and extra time beyond 90)

    Open design decisions (must be resolved before implementation):
        [ ] Exact base bonus/penalty values for each scenario
        [x] "Equalizing goal" definition: ✅ only the final equalizer in a draw — mid-match
            ties subsequently broken do not qualify
        [ ] Losing-goal penalty scope: all GKs/DEFs on pitch at time of concession, or
            starters only?
        [ ] Own-goal as decisive goal: scorer takes the penalty; no assister; no positive
            bonus (own goals cannot "win" for the scoring side)

    Implementation tasks:
        [ ] Extend PlayerMatchStat / match event tracking to record goal_minute and
            compute goal_type (winning / equalizing / losing) post-match from score progression
        [ ] Add applyGameStateBonus step to calculatePlayerScores, after base event scoring
        [ ] Add timing multiplier helper (goalMinuteToTimingMultiplier) to domain/
        [ ] Update seedMatchStats.ts to cover game-state bonus scenarios and assert expected
            values for each time bracket
        [ ] Add vitest coverage: all three scenarios × all five time brackets = 15 test cases
            minimum; plus own-goal edge cases
