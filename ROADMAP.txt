4–6 months

Most projects take longer because:
    Football data quirks
    Scoring edge cases
    Transfer bugs
    Auto-sub bugs
    Data quality issues


What actually takes the longest?

Not the frontend.
Not the APIs.
The scoring engine.

For example:

    Player starts match
    Gets injured after 8 minutes
    Receives yellow card
    Captain doesn't play
    Vice-captain does play
    Bench substitution occurs
    Match is later ruled postponed

Those edge cases consume a disproportionate amount of development time.

Break it into 3 milestones.
Milestone 1 (2–3 weeks) Playable internally.
    Login
    Create league
    Join league
    Build squad
    Save lineup
No scoring.

Milestone 2 (3–5 weeks) Game actually works.
    Data import
    Transfers
    Locking
    Scoring
    Leaderboards

Milestone 3 (2–4 weeks) Production ready.
    Admin tools
    Testing
    Monitoring
    Performance
    Bug fixing
