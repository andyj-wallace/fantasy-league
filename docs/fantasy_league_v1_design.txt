Fantasy League V1 Design

League
- Premier League
- Private leagues only
- Join via invite code
- Free leagues only
- Maximum 50 managers per league
- Join cutoff: Gameweek 25 (system-wide — no new managers may join any league after this gameweek, regardless of when that league was created)

League Administration
- Anyone can create a league
- League creator becomes commissioner/admin
- Admins can:
  - Remove managers
  - Rename league
  - Regenerate invite code
  - Lock league settings after the season starts

Squads
- One team per user per league
- Fixed salary cap: £110M
- 11 starters + 5 bench
- Flexible squad composition
- Must have 2 goalkeepers total
- Starting XI must satisfy formation requirements
- Maximum 3 players from the same club

Transfers
- Unlimited transfers before season start
- Unlimited transfers during mid-season break
- 2 free transfers earned per gameweek
- Unused transfers carry forward
- Maximum banked transfers: 8
- Additional transfers cost -10 points each

Player Pricing
- Monthly price updates

Player Positions
- Goalkeeper (GK)
- Defender (DEF)
- Midfielder (MID)
- Forward (FWD)

Match Locking
- Players lock individually at exact kickoff of their match
- Locked players cannot be transferred, benched, captained, or vice-captained
- Unlocked players remain editable until kickoff

Bench Rules (V1)
- No automatic substitutions in V1 — deferred to V2
- Bench player points are added directly to the team's total score, regardless of whether starters played or formation validity
- V2 will introduce automatic substitutions for non-playing starters

Captaincy
- Captain scores 2x points
- Vice-captain receives the captain bonus if the captain does not play, provided the user has not manually reassigned captaincy before the captain locks at kickoff
- If neither captain nor vice-captain plays, no fallback is required for V1 — this case is left open/optional (may default to the highest-scoring non-captain starter as a convenience; a proper rule is deferred to V2)

Competition
- Total points leaderboard

Tiebreakers
1. Goals scored by selected players
2. Most banked transfers remaining
3. Least money spent on squad
4. If still tied after all of the above, managers share the same league position

Injuries & Suspensions
- No special rules
- Managers may keep players indefinitely
- Cosmetic availability flag only (Available / Out / Questionable, shown on player cards) — does not affect roster rules, scoring, or transfer eligibility. See PlayerAvailabilityStatus in Fantasy League Architecture.txt

Postponed Matches
- 1 free transfer per affected club
- Multiple affected players from the same club count as one club
- Stacks with regular free transfers; still bounded by the hard cap of 8 banked transfers

Examples:
- 3 Arsenal players affected → 1 free transfer
- Arsenal and Liverpool affected → 2 free transfers
- Arsenal, Liverpool, Chelsea affected → 3 free transfers

Scoring

Appearance
- Any appearance: +1

Goals
- Goal (GK): +10
- Goal (DEF): +8
- Goal (MID): +6
- Goal (FWD): +4

Other Positive Events
- Assist: +3
- Clean Sheet (GK): +4
- Clean Sheet (DEF): +4
- No clean sheet bonus for MID or FWD (V1)
- Save (GK): +1 per 3 saves (rounded down)
- Penalty Won: +2

Negative Events
- Yellow Card: -1
- Red Card: -2
- Own Goal: -2
- Penalty Conceded: -1

Squad Builder Player Cards
- Player Name
- Club
- Position
- Current Price
- Total Fantasy Points
- Recent Form
- Availability Status (cosmetic: Available / Out / Questionable)

Recent Form Rules
- Use last 5 matches when available
- If fewer than 5 matches played, use all available matches
- Minimum 3 matches required to display form
- Fewer than 3 matches displays "Insufficient Data"

League Start
- Leagues can be created at any time
- Scoring begins from the next gameweek after joining
- Previous gameweeks are not counted retroactively

League Visibility
- Private leagues only
- Join via invite code
- No public league discovery

Valid Formations
- 3-4-3
- 3-5-2
- 4-3-3
- 4-4-2
- 4-5-1
- 5-3-2
- 5-4-1

Formation Validation
- Exactly 1 Goalkeeper
- 3-5 Defenders
- 2-5 Midfielders
- 1-3 Forwards
- Total 11 players
